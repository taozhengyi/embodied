# 仿真环境

多种仿真环境支持：

- `mujoco/` -> MuJoCo 基础仿真（RL 入门推荐）
- `isaac_sim/` -> NVIDIA Isaac Sim（机械臂/机器人）
- `sapien/` -> SAPIEN 仿真（操作任务）
- `data_collection/` -> 仿真数据采集脚本
- `closed_loop/` -> 闭环测试脚本

## 环境选型

| 环境 | 用途 | 难度 |
|------|------|------|
| MuJoCo | RL 入门，简单机器人 | 低 |
| Isaac Sim | 复杂机器人，高保真 | 中 |
| Sapien | 机器人操作科研 | 中 |
